A **2D Urban City View simulation** developed using **C++ and OpenGL (GLUT)**.  
This project demonstrates fundamental **computer graphics concepts**, including rendering, animation, and scene management.

The simulation features a dynamic urban environment with **buildings, trees, roads, moving cars, clouds, and a day-night cycle (sun & moon transition).**

---

##  Features

- 🏙️ 2D urban city environment rendering  
- 🚗 Moving cars animation  
- ☁️ Animated clouds  
- 🌞 Day and 🌙 Night mode simulation  
- 🌳 Static environment elements (trees, buildings, roads)  

## 🛠️ Technologies Used

- C++  
- OpenGL (GLUT)  
- Computer Graphics Algorithms
